# BUGPAD
 This is my first hardware project  bugpad.
 
A 4 keys micropad to play hillclimb racing with and a rotatory encoder and a oled , 

built for hackclub hackpad mission.

![bug-pad](https://myimgs.org/storage/images/46826/Screenshot2026-09-27123920.png) 

# About
This is a  micropad , with 4 switches , 1 encoder and a oled display . 

the switches work as a arrow key , encoder is for volume , and oled show which key is pressed . 

So you can play hillclimb racing and chrome dino with this bug pad .

# Features 
 - four mechanical switches
 - a encoder for volume
 - a oled display
 - and a insane 3d case
